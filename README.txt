YouTube + Twitch 同時視聴ビューワー
============================

【推奨】 start.bat をダブルクリックで起動
  → ローカルサーバが立ち上がり、自動的にブラウザで開きます。
    YouTube / Twitch の埋め込みAPIが動作するため、一括再生・同期などの機能が使えます。
    Python 3 が必要です（未インストールならエラーが出ます）。
    ポート 8080 が使用中なら、空いている次のポートで起動します。
    サーバはこの PC（localhost）からのみアクセスできます。

【簡易起動】 index.html をダブルクリック
  → file:// プロトコルで開かれるため、簡易モードになります。
    ・各動画は再生できます
    ・「全再生」「全ミュート」「同期」などの一括操作は使えません
    ・@チャンネル指定、配信一覧（にじさんじ / 勢いランキング / ぶいみる）は使えません
    ・各動画のプレーヤー上のコントロールで個別操作してください

公開サイトとして使う場合は DEPLOY.md（Vercel）を参照してください。

使い方
------
1. ツールバーの「レイアウト」を選ぶと、その数だけ空の枠が表示されます。
2. 各枠の入力欄に URL / ID を入れて「表示」を押すと、その枠に配信が表示されます。
   ・YouTube: youtu.be/... / youtube.com/watch?v=... / 動画ID
             youtube.com/@チャンネル（/live）、@チャンネル → いま配信中のライブを表示
   ・Twitch : twitch.tv/チャンネル名 / twitch:チャンネル名 / VOD・クリップの URL
   ・改行やカンマ区切りで複数貼り付けると、空き枠に順番に入ります。
   ・URL を空き枠にドラッグ＆ドロップしても追加できます。
3. 空き枠のボタンから、配信一覧（にじさんじ / 勢いランキング / ぶいみる）を開いて追加できます。
   続けて選ぶと、次の空き枠に追加されます（Esc または × で閉じる）。
4. 空き枠の「💬 この枠にチャットを表示」を押すと、その枠がチャット枠になります。
   上部のメニューで、他の枠に表示している配信を選ぶと、そのチャットが表示されます。
   ・対応: YouTube ライブ / Twitch チャンネル

便利な機能
----------
- 音量    : 実際の音量 = 枠ごとの音量 × マスター音量。マスターを動かしても枠ごとのバランスは保たれます。
- ⇄ 同期  : フォーカス中（なければ先頭）の動画の再生位置に、他の動画を合わせます（ライブは対象外）。
- 🔗 共有 : いまのレイアウトを URL としてコピーします。開いた人は確認のうえ読み込めます。
- 並び替え: 枠の左上をドラッグ。空き枠・チャット枠にドロップすると入れ替えになります。
- 視聴者数: ぶいみるに掲載されている配信（YouTube / Twitch）はそのまま表示されます。
            ⚙ で YouTube Data API キーを設定すると、すべての YouTube ライブで表示されます。
- 枠を閉じた直後は、通知の「元に戻す」で復元できます。

困ったとき
----------
- 「動画が表示されない」 → Python が無い場合は https://www.python.org/ から
  Python 3 をインストールしてから start.bat を実行してください。
- 「埋め込み禁止」エラーが出る動画 → 著作権者や配信者が埋め込みを禁止している
  動画です。「元のページで開く」ボタンから直接視聴してください。
- 「このチャンネルは現在ライブ配信していません」 → @チャンネル指定は配信中のときだけ使えます。

ショートカット
--------------
Space      : すべて再生 / 一時停止 切替
M          : 全ミュート / 解除 切替
R          : すべて先頭から再生（ライブ配信は除く）
F          : 全画面切替
S          : ソロモード切替
H          : ヘッダー表示 / 非表示
1〜6, 8, 9 : レイアウト変更
Del        : フォーカス中の枠を空にする
Esc        : 開いているパネル・設定を閉じる

開発
----
python server.py            … http://localhost:8080 で起動（--open でブラウザも開く）
python -m unittest discover -s tests   … Python のテスト
node --test tests/*.test.js            … URL 解析（assets/parse.js）のテスト
GitHub に push すると .github/workflows/ci.yml で両方のテストが実行されます。
